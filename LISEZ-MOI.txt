CORRECTION V2 :

MISE À JOUR D'UN DÉPÔT EXISTANT :
- Aller dans le dépôt GitHub Dojo-Securite.
- Add file > Upload files.
- Déposer les 8 fichiers extraits du ZIP V2 (pas le ZIP).
- Si GitHub affiche les fichiers existants remplacés, c'est normal.
- Cliquer sur Commit changes.
- GitHub Pages se republie automatiquement; ne pas retourner régler Pages.
- Actualiser le site. Si l’ancienne V1 persiste, fermer puis rouvrir
  l’onglet ou vider les données du site si nécessaire.

Fichiers prêts à déposer à la racine du dépôt GitHub Dojo-Securite.

1. Ouvrir GitHub > dépôt Dojo-Securite > Add file > Upload files.
2. Extraire ce ZIP sur votre ordinateur, sélectionner TOUS les éléments à l'intérieur
   (index.html, sw.js, manifest.webmanifest, LISEZ-MOI.txt, icon.svg
   et les 3 photographies .webp).
   Ne PAS déposer le ZIP seul : GitHub Pages ne décompresse pas automatiquement.
3. Cliquer sur Commit changes.
4. Dans Settings > Pages : Build and deployment / Source : Deploy from a branch.
   Branch : main / Folder : /(root) > Save.
5. Après publication, l'adresse attendue est :
   https://mauropenn.github.io/Dojo-Securite/
   (l'adresse ne fonctionnera qu'après activation et déploiement de GitHub Pages).
